# Philip | IT Portfolio (Django)
## Live Site: https://philipgalloe.pythonanywhere.com

This project is a professional personal portfolio built using the Django Framework. 
It showcases my academic journey at Negros Oriental State University (NORSU) 
and my technical skills

### 🛠️ Technical Stack
* Backend: Python 3.10 / Django 5.x
* Frontend: HTML5, CSS3,BOOTSTRAP,ETC
* Deployment: PythonAnywhere

### 🚀 Setup Instructions
1. Clone the Repo: git clone https://github.com/PHILzz-404/philip-portfolio.git
2. Install Requirements: pip install -r requirements.txt
3. Run Server: python manage.py runserver
